# Sidebar UI Interaction: RabbitMQ 刷新进度提示

## 1. Status Row

侧边栏底部保持一个稳定状态行：

```text
[状态文字]                                      [活动进度条]
```

- 状态文字继续使用现有内容。
- 进度条只表达正在进行，不显示百分比、数字或剩余时间。
- 进度条不覆盖树、搜索框、类型筛选或刷新入口。
- 未刷新时进度条隐藏且停止活动。

## 2. Visible State Matrix

| Condition | Status Text | Progress | Required Result |
|-----------|-------------|----------|-----------------|
| 项目可分析且最新刷新正在执行 | 正在刷新 RabbitMQ 端点 | 可见、活动、不确定 | 旧树仍可浏览 |
| 项目正在索引 | 等待项目索引完成 | 隐藏、停止 | 旧树仍可浏览 |
| 刷新成功且存在 endpoint | 空字符串或现有筛选反馈 | 隐藏、停止 | 展示最新树 |
| 刷新成功且 endpoint 为空 | 未发现 RabbitMQ 端点 | 隐藏、停止 | 展示合法空树 |
| 当前筛选无匹配 | 当前条件无匹配结果 | 隐藏、停止 | 保留完整数据供清除条件恢复 |
| 最新刷新失败 | 刷新失败，已保留上次结果 | 隐藏、停止 | 保留旧树 |
| 项目关闭 | 不再更新 | 不再更新 | 不访问已释放 UI |

## 3. Request Ordering

| Current State | Event | Required Result |
|---------------|-------|-----------------|
| 请求 A 正在执行 | 用户触发请求 B | B 成为最新请求；进度条继续活动 |
| B 仍在执行 | A 完成或失败 | A 被丢弃；文字、进度条和树均不改变 |
| B 完成或失败 | A 仍未返回 | 按 B 的终态隐藏进度条并更新文字或树 |
| B 已结束 | A 随后返回 | A 不得重新激活进度条或覆盖 B 的结果 |

至少使用 10 组反向完成样例验证以上顺序。

## 4. Existing Interaction Compatibility

- 刷新期间允许展开和折叠已有模块，其他模块状态不变。
- 刷新期间允许输入文本搜索和切换 endpoint 类型筛选。
- 搜索或筛选触发树重建时，不得清除“正在刷新”文字或隐藏仍应活动的进度条。
- 最新刷新完成后，模块状态恢复、数量、动态标识、tooltip 和双击导航继续遵循现有规则。
- 进度条状态变化不得调用 endpoint 扫描、tree rebuild 或导航逻辑。

## 5. Visual and Accessibility Behavior

- 使用 IntelliJ Platform 主题感知的进度组件。
- 进度条位于状态文字旁，文字为用户提供明确语义，动画只作为补充反馈。
- 进度条组件名称固定为 `mqTopologyRefreshProgress`，便于自动化测试识别。
- 工具窗口较窄时，状态文字和刷新入口仍可识别，进度条不得覆盖主要内容。
- 固定窄宽度验收时，进度条出现前、出现中和消失后的主要树区域高度保持不变，状态文字与进度条边界不重叠。
- 快速刷新允许提示短暂或不可感知，但刷新结束后不得残留活动状态。

## 6. Timing Evidence

- 先执行 5 次预热，再采集至少 20 次持续 500ms 以上的受控刷新。
- 每次从用户刷新调用提交前开始，到进度条在 UI 状态中同时满足可见和不确定模式时停止。
- 输出 n、p50、nearest-rank p95 和 max；p95 不超过 300ms。
- 成功、合法空结果、失败和索引等待各至少执行 5 次，状态文字出现时进度状态正确率为 100%。

## 7. Safety Boundaries

- 不修改 `RefreshMqIndexAction` 的入口或调用顺序。
- 不修改现有 NBRA、smart-mode、项目关闭和最新请求规则。
- 不新增自定义线程、计时器、锁、缓存、持久化或扫描阶段回调。
- 不修改用户项目，不连接或查询 broker。

## 8. Requirement Mapping

| Interaction Area | Requirements |
|------------------|--------------|
| 活动进度展示 | FR-001–FR-005 |
| 连续刷新生命周期 | FR-004–FR-007 |
| 刷新期间继续浏览 | FR-007–FR-010 |
| 用户项目只读和 broker 隔离 | FR-011 |
